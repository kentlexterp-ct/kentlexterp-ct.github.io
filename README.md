# Kent Lexter Paciones — Portfolio

Static portfolio for Python backend, automation, and AI integration work. It is designed for two audiences: hiring teams considering Kent for remote Python roles and small teams considering a scoped automation project.

## Run locally

No build step or package manager is required. Open `index.html` in a browser, or serve this folder with any static server.

```powershell
py -m http.server 8000
```

Then open `http://localhost:8000`.

## Deploy

GitHub Pages can publish the repository root. The custom-domain-free canonical URL is `https://kentlexterp-ct.github.io/`.

## Files

- `index.html` — semantic content, case studies, metadata, and JSON-LD
- `style.css` — responsive, mobile-first visual system
- `script.js` — accessible mobile navigation, current-section hint, deep-linked case studies
- `resume.pdf` — downloadable resume
- `assets/` — SVG favicon and social sharing card
- `robots.txt`, `sitemap.xml` — crawl discovery

## Before publishing, replace these evidence placeholders

- Project timeline, team/ownership, and technical constraints that have not been verified.
- Measured results: reliability, accuracy, latency, time saved, or conversion impact.
- Screenshots/GIFs, live demos, and sanitized source links for GHL and Workflow Agent.
- Approved testimonials with a real name, role, and project context.

Do not replace placeholders with guessed metrics or client claims.
